Mit Rivals Data synchronisieren

    

    
Rivals Data hat keine offizielle Schnittstelle und blockiert direkte Abfragen aus dem Browser. Deshalb holt nicht diese Seite die Daten, sondern ein kleines Python-Skript: deine öffentlichen Matches und die globalen Helden-Statistiken.

    

      
      
    

    

    
Mit „Jetzt aktualisieren“ bittest du Claude, den Abruf für dich auszuführen und die Matches hier einzutragen – das dauert meist 1–3 Minuten. Das klappt, solange die Claude-Sitzung läuft, in der diese App gepflegt wird. Sonst nutze die Schritte unten.

    

    Selbst abrufen (mit Python)
    
    
      
  1. Einmalig die Bibliothek installieren (Python 3.10 oder neuer):
        
    python -m pip install rivals-api
    2. 
      
  2. Das Skript rivals_sync.py herunterladen – oder den Code kopieren und als Datei rivals_sync.py in einem Ordner speichern.
        
    3. 
      
  3. Den Befehl mit dem Spielernamen von oben im selben Ordner ausführen:
        
    
        Deine Match-History muss im Spiel öffentlich sein. Mit --limit 100 holst du mehr Matches.
    4. 
      
  4. Die erzeugte Datei rivals-sync.json hier importieren. Neue Matches werden ergänzt, bestehende aktualisiert – deine Notizen und Reflexionen bleiben erhalten.

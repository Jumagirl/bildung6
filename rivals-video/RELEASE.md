**Rivals Video** wertet deine Marvel-Rivals-Aufnahmen auf deinem PC aus. Nichts geht ins Internet.

Herunterladen: unten bei «Assets» auf **RivalsVideo.exe** klicken. Anleitung: [rivals-video/README.md](https://github.com/Jumagirl/bildung6/blob/claude/marvel-rivals-improvement-app-e4l00i/rivals-video/README.md).

Beim ersten Start warnt Windows («Der Computer wurde durch Windows geschützt»), weil das Programm nicht signiert ist: «Weitere Informationen» → «Trotzdem ausführen».
